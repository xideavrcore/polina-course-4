# polina-course-4

Лабораторные работы по PHP (сайт **MyTravelNotes**).

Папки `1/`, `2/`, `3/`, ... - это **срезы одного нарастающего проекта** на момент соответствующей лабы (не изолированные мини-проекты). С лабы 2 файлы копятся: следующая лаба = копия предыдущей + новые изменения по методичке.

Документация шагов: `DOCS1.md`, `DOCS2.md`, ...

На Windows (Denwer / OpenServer / XAMPP): скопировать содержимое нужной папки лабы в document root и открыть в браузере.
